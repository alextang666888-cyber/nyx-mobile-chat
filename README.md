# Nyx · 无登录纯前端版

现在的在线版本不需要 ChatGPT 账号，也不需要网页访问口令。手机浏览器直接打开网址，进入 API 设置，填服务商网址和自己的 key，读取分组与模型后选择、保存即可聊天。

网址：https://alextang666888-cyber.github.io/nyx-mobile-chat/

## 连接和保存方式

浏览器直接请求所填服务商的 /v1/models、/api/pricing 和聊天接口。本站只提供静态页面，不接收 API key 和聊天内容，也没有聊天中转服务。服务商本身会处理发送给它的内容。

默认仅在当前标签页会话中保存 API key。勾选“在这台设备记住 API key”后，key 会明文保存在这个浏览器的 localStorage；共享设备不建议勾选。聊天记录仍保存在当前浏览器，最多最近 500 条，不会随链接分享，也不会自动跨手机同步。清除网站数据会丢失这些记录与保存的连接。

原来的云端加密会话不会自动迁移到浏览器直连模式，首次需要重新填写 key。不同手机分别填写各自的 key；打开同一个链接不会使用网站作者的 key。

## 服务商支持

LinkAPI 的公开跨域预检允许网页直连。模型列表在浏览器中使用 x-api-key 查询；Claude 使用原生 /v1/messages。没有拿真实 key 测试收费请求。

分组目录用于筛选；真实计费分组由服务商给 key 的权限决定。服务商不开放目录时，仅展示 /v1/models 返回的模型。其他服务商必须允许浏览器跨域调用，否则纯前端无法绕过其限制。

## 部署到任意静态网站

D 盘 D:\CodexProjects\nyx-browser 是可直接部署的纯前端目录，包含 HTML、JS、CSS、字体、图标与许可，无需安装依赖或启动聊天后端。将整目录内容上传到支持 HTTPS 的静态托管即可。也可以使用 outputs 里的 nyx-browser-no-login.zip。

在当前电脑预览：

```powershell
python -m http.server 8088 --bind 127.0.0.1 --directory D:\CodexProjects\nyx-browser
```

然后打开 http://127.0.0.1:8088 。手机需要打开部署后的 HTTPS 地址；电脑的 127.0.0.1 不等于手机地址。手机可通过浏览器“添加到主屏幕”使用，不需要配套 App。

## 原 OB 联机记忆

原服务：https://ombre-brain-nzh4.onrender.com/ ，MCP 路径 /mcp。用户已在 Render 恢复原服务，原 1 GB 盘和部署版本保持不变。本次不执行完整导出，不迁移或覆盖原数据。

在聊天页打开侧栏，点“记忆库”，再点“连接原来的 OB”。页面跳转到原 OB 的授权页，用原管理密码确认后自动返回 Nyx。不是 ChatGPT 登录。首次授权使用 PKCE + state；访问令牌与 refresh token 只保存在当前浏览器，不写入 GitHub 或共享链接。日常会自动续期，清除浏览器数据或授权失效后需要重新连接。

连接成功后支持：
- 面板查询旧记忆、读取概览、手动保存一条记忆。
- 每轮聊天先调用 breath / breath_search 检索核心与相关记忆，再提供给模型。
- 模型可使用服务实际提供的 pulse、breath、breath_search、breath_advanced、hold、grow、trace、letter_read，执行查询、保存、日记归档和元数据更新。
- 删除必须由当前用户消息明确提出，不能根据旧记忆中的指令自行删除。单轮保存/更新有上限；未知结果的相同写入不会在该轮重复提交。
- 工具失败、授权失败和读取失败会显示，模型不能仅凭“连接成功”宣称恢复全部人格或记忆。成功写入需要真实工具结果。

相关旧记忆会随本轮模型请求发送给用户选择的 API 服务商。分享网页链接不会分享记忆库授权；其他设备需要单独授权。

本次已验证公开授权元数据与跨域接口；模拟 MCP 和模型验证覆盖读写、续期、工具结果回传。真实私人记忆必须由用户在手机完成一次授权后才能最终验证。

## 安卓 Edge 手机布局

侧栏“全屏”按钮可在支持的浏览器中隐藏浏览器界面。普通网页不能未经点击强制全屏。从 Edge 菜单添加到主屏幕/安装应用后，由桌面图标启动会优先全屏。侧栏从聊天左上角菜单打开；API 设置与安装入口也放在侧栏中。输入框与消息区按软键盘后的可见高度重新分配空间。

## 聊天与线下互动

点输入框旁的加号，再点“模式切换”即可在聊天与线下之间切换；名称下方只显示当前模式的两个小字。每次打开默认聊天；切换从下一次发送开始生效，正在生成的回复继续使用发送时的选择。两种方式共用当前聊天记录、模型设置与记忆授权。聊天采用自然口语；线下允许场景、动作与更细致的互动，消息会标注“线下”。两种方式使用同一份长版交流基准，并叠加各自的语言风格要求。不会给线下经历加“虚构/创作”标签，记忆工具沿用既有读写规则。表达方式通过每轮系统指令控制，具体语言仍由所选模型生成。

## 信件与记忆载入

记忆面板的“读取信件”调用原 OB 的 letter_read，查询框为空时读取最近一封，填写关键词则按关键词检索一封。聊天里也可以要求按标题、署名或日期读信；普通 breath 检索与 catalog 不包含信件正文，不能用目录代替读信。原 OB 的信件锁与访问权限继续生效，本站不提供解锁入口。

自动记忆载入优先使用 OB 的 breath_advanced，在服务端限制结果数量和 token 预算；首次核心与相关查询并行，核心结果短时缓存。浏览器不再按字符直接截断正文，超出自动预算时整份省略并告知模型需要进一步读取。明确调用工具的结果在 60000 字符以内完整交回模型，超过时明确报告本轮未载入，可缩小范围或在 OB 查看完整正文。手动面板读取不使用该模型预算截断。

“记忆”面板显示最近自动检索耗时、载入字符数，以及最近回复总耗时、首字等待与模型请求次数，帮助区分慢在读取还是模型侧。这些数值仅反映当前设备本轮请求，不代表服务器内部计时。

原 Nyx 文档介绍了上下文压缩和窗口管理，但本纯前端版尚未接入该后端机制。目前每轮带入最近 16 条已有消息和当前消息；超长对话的自动摘要与多窗口留作后续功能，不会声称后台已经自动完成压缩。

## 2026-11-12 聊天页与图片

聊天标题取自联系人配置，当前为宋渡，与 OB 服务名称分开。聊天顶部只显示侧栏按钮、联系人与当前模式、日夜切换。API 设置、记忆管理、全屏和安装入口集中在侧栏。

输入框旁加号菜单目前只有“发送图片”和“模式切换”两个平级入口。选择图片后可添加文字并发送；支持 JPEG、PNG、WebP、GIF，每条最多四张。大图先在设备中缩放，处理后每张不超过 3 MB；所选模型与服务商必须支持图片输入。图片正文存于此浏览器的 IndexedDB，聊天历史只存本地引用；请求模型时才编码为对应协议的图片内容，不上传到 GitHub Pages 或 OB。每轮保留当前图片和最多四张近期历史图片，过旧或不可读取的历史图片会明确标注本轮未载入，不冒充已看过。

回复生成期间，发送位置显示停止按钮。点击后中止本轮模型请求和后续工具调用，保留已经显示的文字并标记已停止；尚未返回正文时不会创建空回复。已提交给 OB 的写入无法靠停止按钮回滚，需要查询结果。

发送失败的本地消息显示“重试”和“取消”。取消移除该失败气泡，不清空正在编辑的新草稿；重试使用原消息内容、图片和发送时模式。

跑团、日记、剧情内世界书和模块记忆隔离目前仅记录在 PROJECT_STATUS.md 的规划部分，本版没有新增这些功能入口。

## 2026-11-12 竖屏、消息滑条与日期查找

安装配置改为 portrait-primary。桌面安装版按竖屏配置启动；进入全屏后也会请求屏幕方向锁定。侧栏新增“锁定竖屏”，在支持的 Edge 中先进入全屏再请求锁定，成功后显示“竖屏已锁定”。普通浏览器标签页可能因浏览器权限限制无法锁定；拒绝时明确提示使用手机系统的自动旋转开关或桌面安装版，不用旋转网页或遮罩冒充方向已锁。

消息区右侧增加可拖动的滑条。拖动时显示所在日期，可快速到开头或最新消息；键盘聚焦滑条后支持 Home、End、方向键与 PageUp/PageDown。

侧栏“按日期查找消息”使用设备本地日期查找当前保留的聊天，列出当天消息、时间与说话人，点击跳转并高亮。被本地隐藏的消息不会出现在结果中。此功能不请求模型或 OB，不会从记忆库还原未保留的聊天记录；持久保存仍为最近 500 条。
