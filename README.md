# Nyx · 无登录纯前端版

现在的在线版本不需要 ChatGPT 账号，也不需要网页访问口令。手机浏览器直接打开网址，进入 API 设置，填服务商网址和自己的 key，读取分组与模型后选择、保存即可聊天。

网址：https://alextang666888-cyber.github.io/nyx-mobile-chat/

## 连接和保存方式

浏览器直接请求所填服务商的 /v1/models、/api/pricing 和聊天接口。本站只提供静态页面，不接收 API key 和聊天内容，也没有聊天中转服务。服务商本身会处理发送给它的内容。

默认仅在当前标签页会话中保存 API key。勾选“在这台设备记住 API key”后，key 会明文保存在这个浏览器的 localStorage；共享设备不建议勾选。聊天记录仍保存在当前浏览器，最多最近 500 条，不会随链接分享，也不会自动跨手机同步。清除网站数据会丢失这些记录与保存的连接。

原来的云端加密会话不会自动迁移到浏览器直连模式，首次需要重新填写 key。不同手机分别填写各自的 key；打开同一个链接不会使用网站作者的 key。

## 服务商支持

LinkAPI 的公开跨域预检允许网页直连。模型列表在浏览器中使用 x-api-key 查询；Claude 使用原生 /v1/messages。没有拿真实 key 测试收费请求。

分组目录用于筛选；真实计费分组由服务商给 key 的权限决定。服务商不开放目录时，仅展示 /v1/models 返回的模型。其他服务商必须允许浏览器跨域调用，否则纯前端无法绕过其限制。

## 部署到任意静态网站

D 盘 D:\CodexProjects\nyx-browser 是可直接部署的纯前端目录，包含 HTML、JS、CSS、字体、图标与许可，无需安装依赖或启动聊天后端。将整目录内容上传到支持 HTTPS 的静态托管即可。也可以使用 outputs 里的 nyx-browser-no-login.zip。

在当前电脑预览：

```powershell
python -m http.server 8088 --bind 127.0.0.1 --directory D:\CodexProjects\nyx-browser
```

然后打开 http://127.0.0.1:8088 。手机需要打开部署后的 HTTPS 地址；电脑的 127.0.0.1 不等于手机地址。手机可通过浏览器“添加到主屏幕”使用，不需要配套 App。

## 记忆库

这个版本没有访问或改动原来的 Render / OB，没有恢复付费资源。旧记忆暂未接入。纯前端聊天记录不等于长期记忆。之后要接入私有 OB，需要另行安排后台连接，不会把私人记忆接口随公开页面分享。

## 保留的后端方案

本项目根目录 runtime.py 和相关文件保留了先前的 VPS 方案，供之后接 OB 使用；它不参与当前公开网站运行。当前交付的 nyx-browser 目录和纯前端 ZIP 不包含可执行后端。

## 验证

无登录、服务商直连、模型分组读取、模型选择、默认会话保存、可选设备保存、聊天流和两台手机记录隔离均通过模拟测试。LinkAPI 跨域预检已实际检查；真实 key 和真实手机视觉效果仍待验证。
